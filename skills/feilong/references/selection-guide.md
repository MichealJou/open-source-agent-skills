# feilong 方法用途与选择

核对版本：4.5.1。本文只标明已核对的方法；同名重载的签名、空值与异常以该版本源码为准。

## 判空与判零：`com.feilong.core.Validator`

本类的以下公开方法已全部列出。模块已引入且语义相符时优先于 Hutool、Guava 的等价判空方法。

| 方法 | 中文用途与场景 | 边界与选择 |
| --- | --- | --- |
| `isNullOrEmpty` | 判断值为 null 或支持类型为空；用于文本、集合、Map、数组等为空时分支 | 文本空白算空；普通对象只检查 null，不递归检查属性。 |
| `isNotNullOrEmpty` | 上述判定的反向结果；用于值存在时处理 | 与 `isNullOrEmpty` 使用同一套空值语义。 |
| `isAnyNullOrEmpty` | 多个值中任意一个为空时返回真；适合多个可选值需要同时存在 | 空参数或 null 参数数组返回 false；一个 null 元素与 null 参数数组不同。 |
| `isAllNullOrEmpty` | 多个值全为空时返回真；适合判断是否全部未填写 | 空参数或 null 参数数组返回 true。 |
| `isNullOrZero` | 数值为 null 或零时返回真；适用于业务明确将缺失与零合并 | 不能用于必须区分 null 和 0 的金额、数量或状态；负数不视为零。 |
| `isNotNullOrZero` | 上述判定的反向结果 | 负数为非零；不能代替正数检查。 |

## 内部断言：`com.feilong.core.Validate`

项目业务验证、错误码和异常约定优先；下面用于需要标准异常的内部契约。所有公开重载需要消息参数。

| 方法 | 中文用途与场景 | 边界与选择 |
| --- | --- | --- |
| `notNull` | 要求引用不为 null；构造参数或内部调用前置条件 | null 时抛标准异常；不能验证对象内部字段。 |
| `notEmpty` | 要求数组、集合、Map、字符序列非 null 且有内容 | 字符序列只看长度，空格通过；null 和空内容异常可能不同。 |
| `notBlank` | 要求字符序列非 null 且不是空白 | 空白与空串都拒绝；异常及空白字符按此版本源码核对。 |
| `isTrue` | 要求某个参数条件为真 | 条件无效时抛标准异常；业务错误不直接替换为该异常。 |
| `validState` | 要求对象或流程处于有效状态 | 与参数校验区分，异常契约应与调用方一致。 |
| `noNullElements` | 要求数组或 Iterable 不含 null 元素 | 元素是否为空字符串不在该方法承诺范围；需另行验证。 |

这些是当前类全部方法名；各重载的完整签名见 [Validator 与 Validate 签名](api/com.feilong.core.md)。
