# vue3：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

开发 Vue 组件、模板和组合式逻辑时使用。先复用项目组件和 composable，保持已有 Options API、TSX 或 `<script setup>`；只有项目已经使用时才沿用相应风格。

| 方法或能力 | 中文用途和场景 | 优先选择与边界 |
| --- | --- | --- |
| `ref` | 管理可变化的响应式值；模板自动解包 | 新建状态前先检查已有状态来源；脚本中访问 `.value`。 |
| `reactive` | 管理对象形式的响应式状态 | 保持引用与解构的响应性；不要为迎合 API 转换接口原值。 |
| `computed` | 从已有状态计算派生值 | 优先于用 `watch` 手动同步可计算状态；计算函数避免副作用。 |
| `watch` | 监听指定来源并执行副作用 | 网络请求等要处理旧结果、取消和清理；不代替简单派生计算。 |
| `watchEffect` | 自动跟踪同步执行期间读取的响应式依赖 | 依赖不明确、需要明确旧值或执行条件时优先 `watch`。 |
| `onMounted` / `onUnmounted` | 挂载后处理浏览器资源 / 卸载时释放 | SSR 期间不要直接假设 `window` 存在；定时器、监听器要清理。 |
| `props` / `emit` | 父组件传参和子组件事件 | 单向数据流；不要在子组件直接修改父级传入对象来绕过约定。 |
| 组件 `v-model` | 双向绑定组件值 | 保持项目已有模型、字段和值类型，不为方便把 ID 转数字。 |
| `v-if` / `v-show` | 控制创建销毁 / 控制显示 | 按状态保留和切换行为选择，不为微优化改变交互。 |
