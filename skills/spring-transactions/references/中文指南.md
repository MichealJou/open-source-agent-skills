# spring-transactions：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

服务层包含需要原子提交的数据库操作，或排查回滚、并发和事务边界时使用。先查项目 Service、事务管理器和数据源，避免把外部网络请求或设备操作当成可随数据库回滚。

| 方法或能力 | 中文用途和场景 | 优先选择与边界 |
| --- | --- | --- |
| `@Transactional` | 为框架管理的调用划定事务边界 | 放在项目已有服务边界；代理调用、可见性和具体配置会影响生效。 |
| `rollbackFor` | 针对指定异常设置回滚规则 | 先核对项目默认规则和异常链，不把错误吞掉后假定会回滚。 |
| `REQUIRED` | 按传播规则加入或创建事务 | 大多数情况沿用项目默认；核对调用方是否已有事务。 |
| `REQUIRES_NEW` | 独立事务边界 | 有独立提交的业务要求时才用；核对连接资源及外层失败行为。 |
| `readOnly` | 声明只读事务意图 | 不作为权限控制或禁止所有写入的保证；按实际驱动和配置验证。 |
| 事务后事件 | 在合适阶段触发后续处理 | 提交后执行不自动保证消息可靠投递，按项目现有机制设计。 |
