# spring-configuration：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

新增或排查已有 Spring Boot 配置、配置绑定和环境覆盖时使用。先查项目实际配置前缀、部署环境与版本，不随意重命名键或改变部署参数。

| 方法或能力 | 中文用途和场景 | 优先选择与边界 |
| --- | --- | --- |
| `@ConfigurationProperties` | 将相关配置项绑定到类型化对象 | 同一职责的配置适合集中管理；优先项目已有配置类。 |
| `@EnableConfigurationProperties` / `@ConfigurationPropertiesScan` | 注册配置属性类型 | 确认项目已有注册方式；声明类型不一定自动成为 Bean。 |
| `@Validated` 与约束 | 对配置输入执行验证 | 确认当前版本和验证提供者；嵌套对象按实际情况验证。 |
| `Duration` 等带单位类型 | 表达超时及时间长度 | 使用明确单位；数值合法性和默认值按业务要求验证。 |
| Profile / 环境变量 | 根据部署环境选择或覆盖配置 | 验证实际覆盖路径；不提交凭证或依赖默认密码。 |
| `ApplicationContextRunner` | 测试配置绑定与启动条件 | 优先项目已有测试设施；覆盖有效、缺失和非法值。 |
