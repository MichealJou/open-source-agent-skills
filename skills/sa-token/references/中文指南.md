# sa-token：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

仅在模块实际使用 Sa-Token 时参考，先查现有登录、权限、租户与业务错误处理。Felix 已声明的版本与上游推荐版本可能不同；以上游版本建议替换项目版本前须另行确认。

| 方法或能力 | 中文用途和场景 | 优先选择与边界 |
| --- | --- | --- |
| `StpUtil.login` | 按已有登录体系建立登录状态 | 优先项目现有登录服务；多账号体系和 token 返回方式必须保持原契约。 |
| `StpUtil.isLogin` | 按当前登录体系检查是否已登录 | 获取的是当前上下文状态，不能代替资源权限校验。 |
| `StpUtil.checkLogin` | 需要登录时执行校验 | 校验异常的映射与错误码遵循项目；不自行绕过统一拦截链。 |
| `StpUtil.checkPermission` / `@SaCheckPermission` | 按已有权限体系检查操作权限 | 核实拦截器、数据来源、资源归属和租户；有注解不等于配置已生效。 |
| `StpUtil.getSession` | 访问当前体系对应的会话 | 先确定账号、token 或自定义会话作用域及存储实现。 |
| `StpUtil.kickout` / `disable` | 踢下线 / 禁用账号能力 | 两者效果和时效不同，按业务要求和版本验证；不可混用。 |

中文上游原文：[决策](upstream/references/01-decisions.md)、[常见陷阱](upstream/references/02-traps.md)。不因为项目没有使用 Sa-Token 就引入它。
