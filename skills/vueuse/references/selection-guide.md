# vueuse 方法用途与选择

核对版本：14.3.0。本文只标明已核对的方法；同名重载的签名、空值与异常以该版本源码为准。

## 常见组合式函数怎么选

先查项目组件和 composable，功能契约一致再用 VueUse。方法来自 `@vueuse/core` 及其重导出的 shared；生命周期、SSR、并发和数据类型按当前版本核对。

| 方法 | 中文用途与场景 | 选择与边界 |
| --- | --- | --- |
| `useIntervalFn` | 在需要时定时执行函数 | 先看项目实时更新机制；暂停与清理不能代替异步去重和取消。 |
| `useTimeoutFn` | 延时执行函数 | 核对启动、取消和组件卸载；单次简单延时不必额外封装。 |
| `useEventListener` | 注册事件监听并配合生命周期清理 | 避免 SSR 期间直接访问不存在的浏览器对象。 |
| `useDebounceFn` | 高频调用后按防抖策略执行 | 确认尾部触发、取消和提交数据的时序。 |
| `useThrottleFn` | 按节流策略限制高频调用 | 与防抖不是同一行为；核对首尾调用配置。 |
| `useLocalStorage` / `useSessionStorage` | 将状态与浏览器存储关联 | 不保存敏感数据；序列化、跨页面更新与 SSR 需验证。 |
| `useWindowSize` | 响应式读取窗口宽高 | 优先现有布局能力；SSR 初值及监听生命周期需确认。 |
| `useClipboard` | 使用剪贴板 API | 核对浏览器安全上下文、权限和失败处理。 |
| `useFetch` | 组合式 HTTP 请求 | 项目已有客户端、鉴权和错误处理优先，不绕过统一链路。 |
| `useWebSocket` | 管理 WebSocket 连接 | 项目统一实时通信优先；连接认证、重连和清理需验证。 |

完整签名见 [按名称检索的 API 索引](API-INDEX.md)。未列出的函数仍需逐项核对官方文档。
