# vueuse：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 与 Vue、项目 composable 如何分工

Vue `ref` / `computed` / `watch` 负责基础响应式；已有项目 composable、组件、网络和实时通信方案优先。VueUse 仅在实际版本已安装且语义相符时选用，不因为上游标记 `AUTO` 就新增轮询、全局状态或依赖。

| 方法 | 中文用途和场景 | 选择与边界 |
| --- | --- | --- |
| `useEventListener` | 注册事件监听，并结合作用域管理清理 | SSR 不能假定浏览器对象存在；先查项目已有封装。 |
| `useIntervalFn` | 可暂停和恢复的定时执行 | 已有推送优先；异步重叠、失败和旧结果需要单独处理。 |
| `useTimeoutFn` | 可控制的延迟调用 | 核对启动、暂停与卸载行为。 |
| `useDebounceFn` / `useThrottleFn` | 防抖 / 节流高频调用 | 两者触发语义不同，核对首尾执行和最终提交。 |
| `useLocalStorage` / `useSessionStorage` | 与浏览器存储同步状态 | 项目存储方案优先；确认 SSR、序列化和敏感数据策略。 |
| `useMediaQuery` / `useBreakpoints` | 响应式媒体查询 / 断点判断 | 先查项目断点与布局组件；兼顾 SSR 初始值。 |
| `useFetch` | 组合式网络请求 | 项目统一客户端、鉴权、错误处理和 API 契约优先。 |
| `useWebSocket` | 管理 WebSocket 连接 | 项目已有实时通信机制优先；核对认证、重连及释放。 |
