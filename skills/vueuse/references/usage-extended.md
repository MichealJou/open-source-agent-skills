# 常用方法中文说明

说明以当前技能声明的库版本为基准。优先复用项目既有功能；判空、判零和内部断言在语义匹配时先查 Feilong，再查 Hutool；业务异常与项目既有组件优先。方法签名、重载和剩余方法见同目录 API 索引。

| 方法 | 中文用途 | 场景、优先级和边界 |
| --- | --- | --- |
| `useAsyncState` | 把异步操作的结果和状态用于响应式界面 | 已有请求封装优先；并发、取消、权限及错误仍需项目处理。 |
| `useMediaQuery` | 将媒体查询结果转换为响应式状态 | 需要响应视口媒体规则时使用；SSR 初值和浏览器兼容要确认。 |
| `useBreakpoints` | 根据断点判断响应式状态 | 先查项目现有断点常量；避免组件之间断点不一致。 |
| `useElementSize` | 响应式读取元素尺寸 | 确需元素测量时使用；注意元素为空、卸载和观察者生命周期。 |
| `useResizeObserver` | 监听元素尺寸变化 | 项目已有组件能力优先；回调频率和资源清理需要验证。 |
| `useIntersectionObserver` | 观察元素与视口的相交状态 | 适合按可见性触发加载；仍需处理请求并发和重复触发。 |
| `useDocumentVisibility` | 响应式读取页面可见状态 | 适合暂停非必要刷新；后台运行要求以业务为准。 |
| `useOnline` | 读取浏览器在线状态 | 只能作为浏览器网络提示，不能证明服务器或业务接口可用。 |
| `useStorage` | 使状态与浏览器存储同步 | 先用项目存储封装；核对序列化、SSR 和敏感信息。 |
| `useLocalStorage` | 使状态与本地存储同步 | 数据可能跨会话保留；不要存放凭证和敏感内容。 |
| `useSessionStorage` | 使状态与会话存储同步 | 适合会话级持久化；核对标签页和刷新时行为。 |
| `useTitle` | 响应式设置页面标题 | 优先项目路由和国际化标题机制，避免互相覆盖。 |
| `useTimeoutFn` | 可控制的延时执行 | 核对启动、停止、卸载及异步回调的竞争。 |
| `useEventListener` | 绑定浏览器事件并管理清理 | 确认元素和窗口可用，SSR 不直接访问浏览器对象。 |
| `useDebounceFn` | 对高频调用做防抖 | 适合延后执行的交互；核对首尾触发和最终一次请求。 |
| `useThrottleFn` | 对高频调用做节流 | 适合限制执行频率；不能当成防抖的等价替换。 |
