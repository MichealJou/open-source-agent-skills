# 常用方法中文说明

说明以当前技能声明的库版本为基准。优先复用项目既有功能；判空、判零和内部断言在语义匹配时先查 Feilong，再查 Hutool；业务异常与项目既有组件优先。方法签名、重载和剩余方法见同目录 API 索引。

| 方法 | 中文用途 | 场景、优先级和边界 |
| --- | --- | --- |
| `StrUtil.split` | 按指定条件拆分文本 | 已有项目工具优先；核对空片段、限制数量与分隔符规则。 |
| `StrUtil.splitTrim` | 拆分并清理片段两端空白 | 仅在允许清理输入空白时使用；密码、签名、标识等保留原值。 |
| `StrUtil.sub` | 按下标截取文本 | 核对起止位置、越界及负下标语义；结束位置不包含在结果中。 |
| `StrUtil.subBetween` | 提取两个指定标记之间的内容 | 处理格式已知的普通文本；不能代替 HTML、SQL 等结构化解析器。 |
| `StrUtil.format` | 按占位符格式化文本 | 使用前核对占位符和转义；日志继续使用项目日志规范。 |
| `StrUtil.containsIgnoreCase` | 忽略大小写判断包含 | 只在业务允许忽略大小写时用；核对 Unicode 和 null 行为。 |
| `StrUtil.toCamelCase` | 将文本转换为驼峰形式 | 适合明确要求命名转换的场景；接口字段不可随意改名。 |
| `StrUtil.toUnderlineCase` | 将文本转换为下划线形式 | 适合明确约定的名称转换；不能代替数据库字段映射。 |
| `CollUtil.join` | 连接集合元素 | 核对分隔符、null 和元素转换；结构化消息应使用项目序列化机制。 |
| `DateUtil.format` | 格式化日期 | 遵守接口日期格式、时区和精度；项目已有日期工具优先。 |
| `DateUtil.parseDate` | 解析日期文本 | 仅对明确支持的输入格式使用；时间和时区不能凭默认值猜测。 |
| `BeanUtil.copyProperties` | 复制属性到目标对象 | 项目已有转换器和 MapStruct 优先；核对覆盖、null、嵌套和安全字段。 |
