# 常用方法中文说明

说明以当前技能声明的库版本为基准。优先复用项目既有功能；判空、判零和内部断言在语义匹配时先查 Feilong，再查 Hutool；业务异常与项目既有组件优先。方法签名、重载和剩余方法见同目录 API 索引。

| 方法 | 中文用途 | 场景、优先级和边界 |
| --- | --- | --- |
| `eq` | 生成字段相等条件 | 条件构造先复用所属 Service；核对字段类型、空值和租户范围。 |
| `ne` | 生成字段不等条件 | SQL 对 null 的比较并非普通布尔不等；应按业务显式处理。 |
| `gt` | 生成大于条件 | 用于数值或时间下界；核对精度及是否包含边界。 |
| `ge` | 生成大于等于条件 | 用于包含边界的下界；核对业务时区和精度。 |
| `lt` | 生成小于条件 | 用于排除边界的上界；日期区间核对是否应使用下个自然日。 |
| `le` | 生成小于等于条件 | 用于包含边界的上界；核对精度。 |
| `between` | 生成区间条件 | 两端都应符合业务区间和数据库类型；注意边界是否包含。 |
| `in` | 生成集合包含条件 | 限制参数数量；明确集合为空时的预期，不能意外放宽查询。 |
| `notIn` | 生成集合排除条件 | 核对空集合和 SQL null 语义；防止范围扩大。 |
| `like` | 生成包含式模糊条件 | 核对通配符、转义、索引与业务匹配语义。 |
| `likeLeft` | 生成左侧模糊匹配条件 | 核对通配符方向及索引效果，避免与右侧匹配混用。 |
| `likeRight` | 生成右侧模糊匹配条件 | 核对通配符方向及索引效果。 |
| `isNull` | 生成字段 IS NULL 条件 | 仅当确实查数据库 null 时使用；不要等同空串或零。 |
| `isNotNull` | 生成字段 IS NOT NULL 条件 | 核对字段的实际存储约定。 |
| `orderByAsc` | 按字段升序排序 | 字段来自可信映射；同值排序和分页稳定性需确认。 |
| `orderByDesc` | 按字段降序排序 | 客户端传入排序字段必须映射和校验，不能拼接原始 SQL。 |
| `selectCount` | 统计符合条件的记录数 | 优先现有 Service 和框架接口，保持数据权限一致。 |
| `selectOne` | 查询期望唯一的记录 | 需要确保唯一或明确多条处理；不要依赖截断掩盖数据问题。 |
| `selectPage` | 按条件分页查询 | 优先项目分页封装；筛选和分页在数据库完成。 |
| `updateById` | 按主键更新 | 优先已有 Service；核对字段更新策略、租户、事务及并发约束。 |
