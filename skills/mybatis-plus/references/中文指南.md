# mybatis-plus：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 与其他技能如何分工

业务 Service 与框架查询方法优先；通用条件和分页再查 MyBatis-Plus。跨表复杂查询按项目既有 Mapper XML 规则处理；事务查 Spring 事务技能；字段转换查 MapStruct。不要为使用该技能而引入或升级框架。

| 方法或能力 | 中文用途和场景 | 选择与边界 |
| --- | --- | --- |
| `getById` / `selectById` | 按主键获取记录 | 优先所属 Service；查不到、租户和数据权限按项目约定。 |
| `lambdaQuery` / `eq` | 使用属性引用构建相等条件 | 条件缺失可能扩大范围；查询与分页留在数据库。 |
| `in` / `notIn` | 包含或排除一组值 | 核对空集合、分批、SQL null 和权限行为。 |
| `selectOne` | 查询期望唯一的一条记录 | 多条结果必须按现有规则处理，不靠截断掩盖数据问题。 |
| `selectPage` | 分页查询 | 先使用项目统一分页封装；核对拦截器、排序及总数。 |
| `updateById` | 按主键更新 | 核对字段更新策略、null、租户和并发保护。 |
