# 常用方法中文说明

说明以当前技能声明的库版本为基准。优先复用项目既有功能；判空、判零和内部断言在语义匹配时先查 Feilong，再查 Hutool；业务异常与项目既有组件优先。方法签名、重载和剩余方法见同目录 API 索引。

| 方法 | 中文用途 | 场景、优先级和边界 |
| --- | --- | --- |
| `Mapper` | 声明映射器并由处理器生成实现 | 优先复用项目 Mapper 与组件模型；检查注解处理器和生成代码。 |
| `MapperConfig` | 共享映射器配置 | 先复用项目现有配置，不建立平行默认配置。 |
| `Mapping` | 配置单字段来源、目标或策略 | 字段不同名或需要显式控制时使用；核对 null 和字段类型。 |
| `MappingTarget` | 标记被更新的现有对象 | 更新操作时使用；不能等同新对象映射，集合和 null 需验证。 |
| `BeanMapping` | 设置单个 Bean 映射方法的规则 | 调整特定映射时使用；注意与 Mapper 全局配置的优先级。 |
| `Named` | 为映射方法提供限定名称 | 多个候选转换需明确选择时使用；qualifiedByName 名称必须一致。 |
| `BeforeMapping` | 标记映射前回调 | 确需统一准备动作时使用；避免隐藏网络、数据库或业务副作用。 |
| `AfterMapping` | 标记映射后回调 | 确需统一补充映射结果时使用；核对回调条件和生成代码。 |
| `NullValuePropertyMappingStrategy` | 配置更新映射中源属性为 null 的处理 | 仅适用已有目标的更新映射；集合访问器等需检查生成代码。 |
| `NullValueMappingStrategy` | 配置映射方法源参数为 null 时的结果 | 与更新字段为 null 的策略不同，不能混用。 |
