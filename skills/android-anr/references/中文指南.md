# android-anr：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

应用出现 ANR 或需要审查主线程阻塞风险时使用。静态审查与真实设备日志分开：可能阻塞不等于已经发生 ANR。

| 处理方式 | 中文用途和场景 | 优先选择与边界 |
| --- | --- | --- |
| 调用链与线程核对 | 确定可疑代码实际在哪个线程执行 | 根据调用者、调度器和回调证明；不要只凭函数名认定主线程。 |
| 阻塞点分析 | 定位锁等待、同步 I/O、耗时计算等等待 | 区分证据、推测和外部依赖；确认是否真正阻塞。 |
| ANR 堆栈 / 日志 | 确认发生时的线程、等待对象和时间 | 日志缺失时保留不确定性，不把非 ANR 崩溃当 ANR。 |
| 协程调度 | 将适合的阻塞操作放在正确调度器 | UI 修改继续遵守主线程约束；迁移前核对底层 SDK 的线程要求。 |
