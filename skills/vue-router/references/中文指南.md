# vue-router：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

处理路由跳转、参数、导航守卫及路由组件生命周期。先查项目路由、动态权限与守卫，不绕过既有认证。

| 方法或能力 | 中文用途和场景 | 选择与边界 |
| --- | --- | --- |
| `useRouter` / `router.push` | 在组合式组件中获取路由器并导航 | 页面内跳转复用现有导航封装；保留参数类型和跳转历史预期。 |
| `router.replace` | 跳转并替换当前历史记录 | 只在业务确实不需要保留当前历史时用。 |
| `useRoute` | 获取当前路由参数、查询和元信息 | 路由参数可能变化而组件被复用；不要只依赖首次挂载。 |
| `watch(() => route.params...)` | 同一组件复用时响应参数变化 | 指定所需参数，清理或取消过时请求。 |
| `beforeEach` | 全局进入前检查或重定向 | 优先项目现有守卫；异步校验要等待，并避免无限重定向。 |
| `beforeEnter` | 进入特定路由记录前执行 | 相同路由记录的参数变化不一定重新触发，见英文资料。 |
| `onBeforeRouteUpdate` | 组件复用时处理路由更新 | 按 Router 版本与组件现有写法处理离开和错误。 |
