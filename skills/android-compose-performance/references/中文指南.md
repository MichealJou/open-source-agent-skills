# android-compose-performance：中文使用指南

本指南是针对当前收录内容的中文整理，英文上游和许可证保留在 `upstream/`。未列出的方法仍需查对应版本源码和文档。

## 什么时候使用

仅在已有 Compose 页面出现卡顿或需要性能审查时使用。先确认设备、构建类型和实际测量结果；未测量的代码异味只报告为候选原因，不直接声称性能改善。

| 能力 | 中文用途和场景 | 选择与边界 |
| --- | --- | --- |
| `remember` | 在组合生命周期中记住需要复用的值 | 输入变化需要更新时设置正确的 key；不代替状态所有权设计。 |
| `derivedStateOf` | 从频繁变化状态派生较少变化的结果 | 只有减少不必要更新且确实值得时使用；简单计算不要机械包裹。 |
| `LaunchedEffect` | 在组合生命周期中启动与 key 绑定的协程 | key 变化会重新启动；执行设备操作需避免重复副作用。 |
| `snapshotFlow` | 将快照状态读取转为 Flow 以供协程处理 | 按实际版本核对触发与去重，不能当作所有事件的可靠队列。 |
| `LazyColumn` / `LazyRow` | 按需组合长列表中的可见项 | 优先项目已有列表；稳定 key、内容类型和状态保持需验证。 |
| `Modifier.offset { ... }` / `graphicsLayer` | 在合适阶段读取频繁变化值 | 仅在测量证明适合时选择；不得因此改变布局和交互语义。 |
